## 1. 项目解决什么问题

“光电行动台”是一个面向深圳大学光电信息科学与工程本科生的大一学习执行工具。它把课程学习、自主学习、实验室探索、项目训练与复盘放在同一份按日生成的待办清单中，帮助使用者把“想走激光/光电硬件、FPGA 与电路方向”的长期规划，拆成可每天完成、可留痕的行动。

本项目当前以 Windows 本地桌面程序形式运行，适合希望建立稳定学习节奏、记录学习成果并维护个人项目材料的学生。

## 2. 主要功能

### 按日期自动生成大一任务

- 依据设定的学年开始日生成每日任务；
- 按阶段递进安排：大一上学期基础、寒假工具训练、大一下学期光电硬件项目、暑期科研/作品集准备；
- 工作日包含当天课程、课程复盘和自主学习；周末包含周复盘、专项学习和健康规划；
- 大一中后期会加入实验室观察、光强采集仪、TIA、FPGA、PCB 等方向任务。

### 已录入的课表与无课学习时段

- 已按用户提供的深圳大学课表截图写入周一至周五的默认课程；
- 工作日自主学习默认建议安排在第 5–6 节（14:00–15:40）的无课时段；
- 周末自主学习默认建议安排在 09:30–11:00；
- 课表支持在程序的“课表编辑”页面逐行修改，保存后当天课程显示与后续任务即时更新。

### 细化的自主学习卡

每日自主学习会包含以下信息：

- 学习主题与知识分支；
- 建议时长；
- 学习渠道，例如深大课程资料、HDLBits、TI/ADI、AMD/Xilinx、KiCad、LTspice、Thorlabs、Hamamatsu、MIT OCW 等；
- 建议步骤；
- 可保存的交付物，例如 Verilog 文件、仿真波形、Bode 图、参数表、代码仓库提交、项目 README 或论文阅读卡。

### 完成记录与虚拟薪资

- 每项任务可手动勾选完成；
- 当天所有任务勾选完成后，需填写至少 12 个字的“完成凭证/复盘”；
- 满足以上条件时，程序结算当天虚拟薪资 ¥205.48；
- 记录本地保存于当前 Windows 用户的 `%APPDATA%\SZULightTrack-data.json`。

> 重要：程序不能自动判断用户是否真的上课、学习或完成实验。勾选、完成凭证和薪资结算均基于用户如实记录。

### Windows 启动方式

- 双击启动脚本、HTA 程序或文件夹内快捷方式可打开；
- 提供安装和卸载开机自启的脚本；
- 当前桌面快捷方式与 Windows 启动项均配置为使用本项目桌面文件夹中的程序。

## 3. 安装方法

### 环境要求

- Windows 10 或 Windows 11；
- 系统自带 `mshta.exe` 与 Windows Script Host；
- 不需要安装 Python、Node.js 或额外依赖。

### 本地运行

1. 保持整个“光电行动台”文件夹结构不变；
2. 打开 `outputs/SZULightTrack.hta`，或双击 `outputs/启动深大光电行动台.vbs`；
3. 首次运行后，在程序中点击“课表编辑”，检查学年开始日与各工作日课程；
4. 点击“保存设置”。

### 启用开机自启（可选）

1. 双击 `outputs/安装开机自启.cmd`；
2. 下次登录 Windows 时，行动台会自动打开；
3. 如需关闭开机自启，双击 `outputs/卸载开机自启.cmd`。

## 4. 使用方法

1. 每天打开行动台，确认页面顶部日期正确；
2. 查看当天的“校内课程”“课程复盘”“自主学习”和可能出现的“实验室/项目”任务；
3. 自主学习请优先使用任务中给出的建议时段，避免与已录入课程冲突；
4. 每完成一项任务，勾选任务前的复选框；
5. 在“今日完成凭证/复盘”中记录代码文件、实验数据、题目编号、笔记链接或问题复盘；
6. 保存复盘后，若当天全部任务均完成，系统自动增加 ¥205.48 虚拟薪资；
7. 如遇调课、停课或新增课程，点击“课表编辑”，修改对应星期课程后保存。

## 5. 输入输出实例

### 输入：课表编辑

在“周四课程”输入框中填写或修改：

```text
第1–2节 高等数学A(1)（5–18周）；第3–4节 网球俱乐部；第11–12节 C程序设计
```

保存后，周四页面会生成一项“校内课程”任务，并将自主学习建议安排在第 5–6 节。

### 输出：当天任务

以一个工作日为例，程序可能生成：

```text
校内课程：第1–2节 高等数学A(1)；第3–4节 网球俱乐部；第11–12节 C程序设计
课程复盘：整理笔记、完成 2–4 题或 1 页总结（45 分钟）
自主学习｜LTspice：TIA 直流工作点与交流带宽（60 分钟）
建议时段：第5–6节（当天无课，14:00–15:40）
渠道：ADI 应用笔记
交付：Bode 图和带宽结论
```

### 输入：完成凭证

```text
完成高数第 2.3 节第 4、7 题；TIA 仿真已保存为 tia_ac.asc，Bode 图写入实验笔记。
```

### 输出：结算结果

当当天全部任务已勾选，且完成凭证达到 12 个字后：

```text
已结算今日 ¥205.48
目前薪资：¥205.48
```
